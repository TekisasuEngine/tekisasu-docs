# Tekisasu Engine documentation

This repository contains the source files of [Tekisasu Engine](https://github.com/TekisasuEngine/tekisasu)'s documentation, in reStructuredText markup language (reST).

They are meant to be parsed with the [Sphinx](https://www.sphinx-doc.org/) documentation builder to build the HTML documentation on [Tekisasu's Developer Resources website](https://dev.tekisasu.com).

## Theming

The Tekisasu Engine documentation uses the default `sphinx_rtd_theme` with many
[customizations](_static/) applied on top. It will automatically switch between
the light and dark theme depending on your browser/OS' theming preference.
